# Personal Portfolio Website

A professional personal portfolio website showcasing my technical skills, projects, education, achievements, and certifications. The website is designed to present my work and learning journey as an aspiring IT professional interested in data analytics, software development, and digitalization.

## About Me

Hi, I'm Shiv, an aspiring IT professional passionate about using technology to solve practical problems.

I work with Python and Microsoft Excel for data analysis and dashboard development, and I use HTML, CSS, and JavaScript to build interactive web applications. I continuously improve my technical skills through hands-on projects and independent learning.

I am interested in IT Ausbildung opportunities, internships, and entry-level opportunities where I can apply my skills and continue learning.

## Features

- **Professional Homepage:** Introduction, career interests, and featured projects.
- **About Me:** Overview of my technical interests and learning journey.
- **Education:** Academic background and educational milestones.
- **Achievements:** Highlights of academic and volunteering experiences.
- **Technical Skills:** Overview of programming, data analysis, visualization, and web development skills.
- **Projects Portfolio:** Dedicated page showcasing Excel, Python, and web development projects.
- **Project Filtering:** Filter projects by technology or category.
- **Certifications:** Dedicated page displaying completed courses and certificates.
- **Certificate Search and Filtering:** Find certificates using search and category filters.
- **Contact Section:** Links to email, GitHub, LinkedIn, and social profiles.
- **Responsive Design:** Layout designed to adapt to different screen sizes.
- **Dark Theme:** Dark background with blue accents and interactive hover effects.

## Technologies Used

- **HTML5** — Website structure and semantic markup.
- **CSS3** — Styling, responsive layouts, animations, and visual design.
- **JavaScript** — Project filtering, certificate search, and interactive functionality.
- **Git & GitHub** — Version control and project hosting.

## Getting Started

You can run this website locally without installing any frameworks or packages.

### 1. Clone the Repository

Replace `personal-portfolio` with the actual GitHub repository name.

```bash
git clone https://github.com/yadavshivkumar/personal-portfolio.git
```

### 2. Open the Project Folder

```bash
cd personal-portfolio
```

### 3. Run the Website

Open `index.html` in your browser.

For a better development experience, you can use the Live Server extension in Visual Studio Code.
